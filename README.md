# Buyer Bot — расчёт под ключ из Китая

Telegram-бот для байера: Poizon / Taobao / 1688 → Россия.

## Быстрый старт

### 1. Создай бота

У @BotFather: `/newbot` → получи `BOT_TOKEN`.
У @userinfobot: узнай свой `ADMIN_USER_ID`.

### 2. Установи зависимости

```bash
pip install -r requirements.txt
```

### 3. Создай .env

```bash
cp .env.example .env
# Открой .env и вставь токен и свой user_id
```

### 4. Запусти

```bash
python main.py
```

## Что умеет бот

| Функция | Описание |
|---|---|
| **Авто-парсинг** | Определяет площадку по ссылке, пытается извлечь цену и название |
| **Умный диалог** | Задаёт только нужные вопросы (цена, размер, город, доставка) |
| **3 пресета** | Быстро (7–14 дн) / Стандарт (14–21 дн) / Дешевле (21–40 дн) |
| **Режим клиента** | Цена без маржи |
| **Режим байера** | С маржой и чистой прибылью |
| **История** | Последние 20 расчётов, повтор в 1 клик |
| **Корзина** | Несколько товаров, суммарный расчёт |
| **Код расчёта** | Короткий код → клиент открывает через deep-link |
| **Шаблоны сообщений** | Готовый текст для пересылки клиенту |
| **Курс ЦБ РФ** | Автообновление каждый час, предупреждение об устаревании |
| **Маржа по ступеням** | Разный % для разных сумм, минимум в рублях |

## Команды

```
/start       — приветствие
/manual      — ручной ввод (без ссылки)
/calc        — то же, что /manual
/cart        — корзина
/history     — история расчётов
/settings    — курс валюты и маржа
/resetmargin — сбросить маржу к умолчаниям
/cancel      — отменить текущий расчёт
/help        — справка
```

## Настройка маржи

В `/settings` → «Изменить маржу» введи ступени:

```
0:15, 3000:12, 10000:10, 25000:8
```

Формат: `порог_рублей:процент`, разделитель `,`.
Минимальная маржа фиксирована = 500 ₽ (можно изменить в `config.py`).

## Публичная ссылка на расчёт

После сохранения бот выдаёт код (например `AB3K9F`).
Клиент открывает: `https://t.me/ВАШ_БОТ?start=share_AB3K9F`
Видит расчёт без маржи.
